### 🛠️ Стилістичні принципи

- **Естетика**: Dark Minimalist / High-Tech Cyberpunk.
- **Колірна палітра**:
  - Базовий фон: Deep Dark Charcoal (`#0a0b0e`, `#111318`).
  - Акцентні кольори: Електричний бірюзовий / Неон (`#00f0ff`, `#00e5ff`).
  - Семантичні статуси: Лайв-зелений (`#10b981`), попередження (`#f59e0b`), помилка (`#ef4444`).
- **Типографіка**: `Inter` для інтерфейсу та читабельного тексту, `JetBrains Mono` для технічних параметрів, таймкодів та бітрейту.
