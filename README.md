### ⚛️ Лабораторна робота №4 (`lab4/`)

**Реалізація сторінок (Views) та компонентів із модульним CSS (CSS Modules):**

- 📖 **[lab4/README.md](lab4/README.md)** — Детальний опис сторінок, CSS-модулів, компонентів та інструкція із запуску.
- 🎨 **Стилізація**: Власна дизайн-система з Lab 2 на базі **CSS Modules (`*.module.css`)** без жодних сторонніх CSS-фреймворків.
- 📄 **Сторінки**:
  - `HomePage` — Головна вітрина: Hero Spotlight, таймлайни продовження перегляду, сітки популярних серіалів, аніме та фільмів, маніфест-панель.
  - `CatalogPage` — Каталог із пошуком, фільтрацією за типами релізів (серіали/аніме/фільми) та сортуванням.
  - `TitlePage` / `PlayerPage` — Сторінка тайтлу з інтерактивним HUD плеєром (16:9, звук, таймлайн), карткою телеметрії edge-вузла, перемикачем шлюзів та списком епізодів.
  - `AuthPage` — Термінал авторизації (Вхід / Реєстрація) з підтримкою Passkey та GitHub ID.
  - `ProfilePage` — Особистий кабінет оператора з телеметрією та збереженими закладками.
- 🛠️ **Стек**: React 19, Vite, React Router DOM 7, CSS Modules.
