# 🎬 DYVYLO — Лабораторна робота №4 (Views & CSS Modules)

> Реалізація користувацького інтерфейсу, сторінок та компонентної бази веб-застосунку на React + Vite із використанням модульного CSS підходу (**CSS Modules**) без сторонніх CSS-фреймворків.

---

## 🎨 Дизайн та стилістична концепція

Дизайн реалізовано на основі дизайн-системи **Лабораторної роботи №2**:
- **Стилістика**: High-Tech Cyberpunk / Dark Brutalist Minimalist.
- **Дизайн-токени**: палітра кольорів (`tokens.css`), глибокий вугільний фон (`#08080a`), неоновий бірюзовий акцент (`#00f0ff`), точні радіуси скруглень (2–3px), моноширинний шрифт `JetBrains Mono` для технічних параметрів та `Inter` для інтерфейсу.
- **⚠️ Без використання сторонніх CSS фреймворків** (Tailwind, Bootstrap, Materialize тощо). Усі стилі написані власноруч із використанням нативного для Vite підходу **CSS Modules (`*.module.css`)**, що забезпечує повну ізоляцію класів без глобальних конфліктів.

---

## 📄 Реалізовані сторінки (Pages / Views)

У проєкті реалізовано 4 повноцінні маршрутизовані сторінки + кабінет оператора:

1. **`HomePage` (Головна вітрина)**
   - **Hero Spotlight**: Головний банер топового релізу з бейджами якості (4K UHD, HDR10+, рейтинг IMDb), описом та кнопками швидкого старту.
   - **Продовжити перегляд**: Стрічка карток епізодів з таймкодами та прогрес-барами перегляду.
   - **Тематичні розділи**: Сітки постерів популярних серіалів, культового аніме та фільмів у 4K HDR.
   - **Маніфест агрегатора**: Інформаційний блок із живою телеметрією активного стрімінг-вузла.

2. **`CatalogPage` (Каталог та пошук)**
   - Панель швидкого пошуку за назвою, жанром та творцями.
   - Фільтрація за категоріями: **Всі релізи**, **Серіали**, **Аніме**, **Фільми 4K**.
   - Сортування за **рейтингом** або **роком випуску**.
   - Адаптивна сітка медіа-карток з відображенням кількості знайдених тайтлів.

3. **`TitlePage` / `PlayerPage` (Сторінка тайтлу та відеоплеєр)**
   - Повноекранний відеоплеєр 16:9 із напівпрозорим **HUD-оверлеєм**:
     - Кнопка відтворення / паузи.
     - Інтерактивний скрубер прогресу.
     - Регулятор гучності з іконкою та повзунком (Slider / Mute).
     - Вибір аудіодоріжки дубляжу та субтитрів.
   - **Картка живої телеметрії**: моніторинг бітрейту (38.4 Mbps), затримки шлюзу (18.2 ms), буфера та FPS.
   - **Технічна специфікація**: роздільна здатність, аудіокодеки, студії дубляжу, тривалість.
   - **Шлюз ретрансляції**: інтерактивний вибір активного проксі-вузла (HDRezka, UAKino, Eneyida).
   - Список серій сезону з таймкодами та синопсисами.

4. **`AuthPage` (Вхід та реєстрація)**
   - Кіберпанк-термінал авторизації оператора.
   - Перемикач вкладок «Вхід» / «Реєстрація вузла».
   - Стилізовані поля вводу з іконками, чекбокс запам'ятовування сесії.
   - Кнопки швидкого входу через **Passkey** та **GitHub ID**.

5. **`ProfilePage` (Особистий кабінет оператора)**
   - Картка статусу оператора `@operator` з аптаймом 99.98% та статистикою переглядів.
   - Список збережених закладок (обраного) у вигляді інтерактивної сітки.

## 🧩 Структура компонентів та CSS Modules

Кожен компонент ізольований у власному файлі зі своїм модулем стилів:

```text
lab4/src/
├── components/
│   └── ui/
│       ├── Badge/            # Badge.jsx, Badge.module.css
│       ├── Button/           # Button.jsx, Button.module.css
│       ├── Card/             # Card.jsx, Card.module.css
│       ├── Input/            # Input.jsx, Input.module.css
│       └── Modal/            # Modal.jsx, Modal.module.css
│
├── features/
│   ├── catalog/
│   │   └── components/
│   │       ├── EpisodeCard.jsx    # EpisodeCard.module.css
│   │       ├── FilterPanel.jsx    # FilterPanel.module.css
│   │       ├── HeroSpotlight.jsx  # HeroSpotlight.module.css
│   │       └── MediaCard.jsx      # MediaCard.module.css
│   └── player/
│       └── components/
│           ├── PlayerViewport.jsx # PlayerViewport.module.css
│           └── TelemetryCard.jsx  # TelemetryCard.module.css
│
├── layouts/
│   ├── Header.jsx            # Header.module.css
│   ├── Footer.jsx            # Footer.module.css
│   └── MainLayout.jsx        # MainLayout.module.css
│
├── pages/
│   ├── HomePage.jsx          # HomePage.module.css
│   ├── CatalogPage.jsx       # CatalogPage.module.css
│   ├── TitlePage.jsx         # TitlePage.module.css
│   ├── AuthPage.jsx          # AuthPage.module.css
│   └── ProfilePage.jsx       # ProfilePage.module.css
│
├── styles/
│   ├── tokens.css            # Дизайн-токени Lab 2
│   └── base.css              # Базові скидки та типографіка
│
└── data/
    └── mockData.js           # Каталог релізів, епізодів та стрімінг-вузлів
```

## 🚀 Інструкція із запуску

### 1. Запуск сервера розробки
```bash
# З кореня проєкту:
npm run dev

# Або з папки lab4:
cd lab4
npm run dev
```
Сервер запуститься за адресою: `http://localhost:5173/`.

### 2. Збірка для production
```bash
npm run build
```
Vite оптимізує та об'єднає CSS модулі у фінальний мініфікований бандл.
