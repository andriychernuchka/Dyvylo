# 🎬 ДИВИЛО (Dyvylo) — Лабораторна робота №2
## Повна цифрова дизайн-система, UI Kit та інтерфейс веб-платформи

---

### 📌 Опис проєкту
**«ДИВИЛО»** — це концептуальний веб-сервіс, український архітектурний медіа-архів та розподілений стрімінг-вузол нового покоління.
Дизайн платформи побудований на естетиці **архітектурного мінімалізму / кіберпанк-бруталізму**:
- Глибока темна палітра поверхонь (`#08080a`, `#0f0f13`, `#15151b`, `#121217`)
- Фірмовий кобальтовий електричний акцент (`#3b82f6`)
- Строга мікрогеометрія скруглень (`2px radius`)
- Тонкі лінії та прозорі контури (`rgba(255, 255, 255, 0.07 – 0.12)`)
- Типографіка: **Inter** (контент) та **JetBrains Mono** (технічна телеметрія, бітрейти, статуси)

### 🎨 Огляд сторінок та компонентів

1. **`components.html` (Design System & UI Kit)**
   - Зібрані всі дизайн-токени, зразки кольорів (Swatches).
   - Типографічна шкала від Display H1 до JetBrains Mono коду.
   - Стрімінгові бейджі: 4K UHD, HDR10+, Dolby Vision, 18+, студії озвучки (Цікава Ідея, НеЗупиняй, В одне рило тощо).
   - Всі типи та розміри кнопок, стани Hover/Disabled.
   - Елементи форми: поля пошуку з шорткатом `⌘K`, випадаючі списки, чекбокси, тогли.
   - Медіа-картки постерів та епізодів з прогрес-барами.
   - Телеметрія плеєра та системні тост-повідомлення.

2. **`index.html` (Головна вітрина / Каталог)**
   - Фірмова шапка з логотипом-вічком `[ · ]` та навігацією.
   - Головний Hero-банер з інтерактивним оптичним фреймом та прямим переходом у плеєр.
   - Рядок швидкого продовження перегляду з таймлайнами прогресу.
   - Сітка популярних серіалів та кінопрем'єр у 4K HDR.
   - Маніфест сервісу та технічний футер зі статусом Київського вузла.

3. **`player.html` (Плеєр / Перегляд)**
   - 16:9 екран кінозалу з напівпрозорим HUD-оверлеєм.
   - Інтерактивний скрубер з буферизованим кешем і таймкодами.
   - Кнопки перемотування, вибір доріжок озвучки, субтитрів, якості та швидкості.
   - Діагностична плашка телеметрії (бітрейт 28.4 Mbps, HEVC кодек, 0 drop frames, пінг 18ms).
   - Бічна панель вибору серій сезону.

4. **`title.html` (Сторінка тайтлу)**
   - Кінематографічний бекдроп.
   - Майстер-постер та технічна специфікація релізу (формат, аудіодоріжки, студії).
   - Перемикач сезонів та детальний список епізодів з синопсисами.
   - Блок акторського складу.
   - Відгуки спільноти з оцінками.

5. **`search.html` (Пошук та фільтрація)**
   - Пошуковий рядок з автодоповненням.
   - Фільтрація за типом, якістю, студіями озвучки, жанрами та рейтингом IMDb.
   - Чіпи активних фільтрів з можливістю швидкого видалення.
   - Пагінація результатів.

6. **`profile.html` (Особистий кабінет)**
   - Профіль архітектора вузла `@sespure` зі статистикою переглядів та віддачі P2P.
   - Керування збереженими тайтлами та історією.
   - Налаштування розміру локального SSD-кешу та пріоритетної озвучки.

7. **`auth.html` (Авторизація та модальні вікна)**
   - Модалка входу з підтримкою Passkey та GitHub ID.
   - Модалка реєстрації нового вузла з індикатором стійкості пароля.
   - Довідник гарячих клавіш (Space, F, T, J, L, M, C, ⌘K).
   - Модальне вікно вибору сервера з живим пінгом.

### 🛠 Як імпортувати в Figma (Плагіни)
Файли оптимізовані для плагінів прямого імпорту HTML/CSS у Figma (наприклад **html.to.design**, **Figma to HTML / HTML to Design**):
1. Відкрийте Figma та створіть новий файл проєкту.
2. Запустіть плагін (наприклад `html.to.design`).
3. Виберіть режим **«Local file»** або вкажіть локальний URL (якщо запущено локальний сервер `npx serve lab2`).
4. Почніть з імпорту `components.html` — це створить акуратну сторінку з усіма компонентами та автолейаутами.
5. Далі імпортуйте цільові екрани (`index.html`, `player.html`, `title.html`, `search.html`, `profile.html`, `auth.html`).
